# 💳 Credit Card Financial Analytics & Weekly Performance Dashboard

## 📌 Project Overview

This project is an end-to-end **Credit Card Financial Analytics Dashboard** developed using **Power BI, SQL, Excel, and DAX**.

The dashboard provides a comprehensive view of credit card transactions, customer demographics, revenue performance, transaction trends, and weekly business performance.

The project also includes a **Weekly Status Report** focused on Week 52 performance and key business insights.

---

## 🎯 Project Objective

The main objective of this project is to develop an interactive credit card dashboard that helps stakeholders:

- Monitor weekly credit card performance
- Analyze revenue and transaction trends
- Understand customer demographics
- Compare current-week and previous-week performance
- Analyze card categories and expenditure types
- Identify high-performing customer segments
- Track key business KPIs
- Support data-driven business decisions
